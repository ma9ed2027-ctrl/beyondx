# Beyond X — الموقع المنظم (NL / EN)

هذه نسخة موقع ثابت (Static Website) بدون React أو مكتبات أو إعدادات بناء. اللغة الهولندية افتراضية، ويمكن التحويل إلى الإنجليزية من أعلى الصفحة. لا توجد اشتراكات أو قاعدة بيانات مطلوبة لتشغيله.

## الملفات

```text
beyondx-clean-site/
├── index.html                  # هيكل الصفحة وأقسامها فقط
├── assets/
│   ├── css/
│   │   └── styles.css          # كل الألوان والتصميم والتجاوب
│   └── js/
│       ├── site-data.js        # النصوص NL/EN والخدمات والشراكات وبيانات التواصل
│       └── main.js             # ترجمة الواجهة وعرض البطاقات والتفاعل
├── robots.txt
├── sitemap.xml
└── README-AR.md
```

## كيف تعدّل بسرعة؟

1. **تعديل نصوص الموقع:** افتح `assets/js/site-data.js` وعدّل النص المطلوب في `text.nl` و`text.en`.
2. **إضافة خدمة:** أضف عنصرًا جديدًا إلى `services` بالنص الهولندي والإنجليزي. ستظهر البطاقة آليًا دون تعديل HTML.
3. **إضافة نوع شراكة:** أضف عنصرًا إلى `partnerships`، وسيظهر آليًا.
4. **تغيير عبارات الأساس التقني:** عدّل `foundation.nl` و`foundation.en`. القائمة مختصرة وعامة عمدًا.
5. **تغيير الهوية البصرية:** افتح `assets/css/styles.css` وعدّل القيم في أول الملف (`:root`).
6. **تفعيل البريد:** عند تفعيل `partners@beyondx.eu` واختبار إرسال واستقبال الرسائل، غيّر `emailEnabled: false` إلى `true` داخل `site-data.js`. قبل التفعيل يظهر نص محايد بدل زر بريد لا يعمل.
7. **إضافة قسم جديد:** أضف عنصر `<section>` في `index.html` ونصوص الترجمة إلى `site-data.js`. يمكنك إعادة استخدام أصناف CSS القائمة.

## تشغيله محليًا

أفضل معاينة عن طريق خادم محلي:

```bash
cd beyondx-clean-site
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## نشره

ارفع الملفات كلها كما هي إلى استضافة Static HTTPS (مثل Cloudflare Pages)، مع ضبط نطاق `beyondx.eu`. يجب أن تبقى بنية المجلدات كما هي.

## مبادئ المحتوى

- خدمات تقنية عامة مناسبة لمؤسسات مختلفة الأحجام، دون مبالغة في القدرات أو وعود غير متحققة.
- الشراكة هي المدخل الرئيسي، لكن الموقع لا يدعي وجود شراكات مُبرمة بالفعل.
- الشبكات جزء من الخدمات التقنية وليست الهوية الوحيدة.
- تفاصيل الإقامة أو الإجراءات القانونية الشخصية **غير مذكورة** في الموقع.
- البريد مجرد عنوان مقترح حتى يتم تفعيله. لا توجد استمارة بيانات، تحليلات، أو Cookies تسويقية.
- لم يجرِ شراء النطاق أو رفع الملفات تلقائيًا من خلال هذه الحزمة.

## تحسين لاحق عند الحاجة

إذا أردت أن تُفهرس النسخة الإنجليزية بشكل مستقل في Google، أنشئ مسارًا إنجليزيًا منفصلًا `/en/` وأضف روابط `hreflang`؛ زر اللغة الحالي يبدل النص في الصفحة نفسها.
